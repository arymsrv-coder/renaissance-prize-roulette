# RenAIssance Prize Roulette

A weighted prize wheel themed around the RenAIssance artwork. Tap the wheel (or the ribbon) to spin;
the winner gets a "hands touching" celebration with confetti.

**Play it:** https://arymsrv-coder.github.io/renaissance-prize-roulette/

## Odds
₱20 30% · ₱10 28% · ₱5 15% · ₱1 10% · ₱50 9% · ₱100 5% · ₱500 2.5% · ₱1000 0.5%

Edit the `weight` values in the `SLICES` list near the top of the script in `index.html` to retune them.
Slice size on the wheel is proportional to its odds.

Single static page, no build step. Open `index.html` or serve the folder with any static host.
